# Icons

One icon per part of the project (black on transparent, 512×512 SVG).

| File | What it is |
|---|---|
| `rat-king.svg` | **Rat King**: the peer-to-peer mesh |
| `counter-tally.svg` | **Countertally**: counting the real lung-sickness outbreak |
| `tail-count.svg` | **Tail Count**: encrypted family check-ins |
| `taster.svg` | **Taster**: water reports and unsafe-recycler alerts |
| `sos.svg` | **SOS**: calls for help that reach every level |

`light/` holds light copies for dark backgrounds (the README uses them in GitHub's dark
mode). After changing a design, regenerate them with `python tools/light_icons.py`.
The live dashboard tints the black originals itself.
